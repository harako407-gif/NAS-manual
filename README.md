# 시놀로지 NAS 사용자 매뉴얼

사내 담당자 한 명이 브라우저에서 내용을 편집하고, 최종적으로 편집 기능이 없는 단일 정적 HTML을 내려받아 사내 서버에 올리는 매뉴얼입니다.

## 편집 흐름

가장 쉬운 방법은 프로젝트 폴더의 `START_MANUAL_EDITOR.cmd`를 더블클릭하는 것입니다. 서버가 준비되면 브라우저가 자동으로 열립니다. 검은 서버 창은 편집하는 동안 닫지 마세요.

1. 개발 서버를 실행하고 브라우저에서 사이트를 엽니다.
2. 오른쪽 위 `편집 시작`을 누릅니다.
3. `문서 설정`에서 NAS 주소, Drive 웹 주소, Team Folder, 문의처를 회사 값으로 바꿉니다.
4. 각 단계의 입력란을 수정하고 자리표시자에 PNG, JPG, WebP 또는 GIF를 넣습니다.
5. `JSON 백업`으로 문서와 미디어를 함께 백업합니다.
6. `배포 전 검수`를 실행한 뒤 `정적 HTML 내보내기`를 누릅니다.

`JSON 자동 저장 설정`을 처음 한 번 누르고 저장할 JSON 파일을 선택하면, 이후 글·순서·사진·주석이 변경될 때마다 같은 파일을 자동으로 갱신합니다. 브라우저를 다시 열었을 때 권한 확인이 표시되면 `자동 저장 다시 연결`을 누르세요. 자동 저장을 중단하려면 `자동 저장 끄기`를 사용합니다.

편집 모드에서는 표지 문구, 안내문, 빠른 메뉴 문구도 직접 수정할 수 있습니다. 왼쪽 목차와 빠른 메뉴의 `⋮⋮` 손잡이를 끌어서 장과 메뉴 순서를 바꿀 수 있으며, 화살표 버튼도 같은 기능의 보조 수단으로 사용할 수 있습니다.

`문서 설정`에서는 전체 글자 크기를 80~140%로 조절하고 표지, 안내문, 빠른 메뉴, 연결 정보, 참고자료, 하단 정보의 표시 여부를 선택할 수 있습니다. 각 단계에서는 사진 영역과 주의·참고 박스를 추가하거나 완전히 삭제할 수 있습니다.

장 제목, 장 설명, 단계 제목, 단계 설명, 확인 항목, 사진 제목·설명, 주의·참고 박스, 빠른 메뉴는 각 편집 입력란 옆의 `글자 px`에서 개별 글자 크기를 지정할 수 있습니다. `기본`을 누르면 문서 기본 크기로 돌아갑니다.

사진이 들어 있는 단계의 `사진 주석 편집`을 누르면 색상과 굵기를 선택하여 사각형, 원, 화살표, 자유선, 텍스트를 사진 위에 직접 추가할 수 있습니다. `사진에 적용`으로 저장한 주석 사진은 JSON 백업과 정적 HTML에도 포함됩니다.

주석을 저장한 뒤에는 `편집본 제거·원본 복원`으로 원래 사진을 다시 표시할 수 있습니다. 주석 편집기를 다시 열어 `원본으로 되돌리기`를 누른 뒤 저장하는 방법도 사용할 수 있습니다.

편집 내용은 현재 브라우저에만 저장됩니다. 여러 사람이 함께 편집하거나 다른 PC와 자동 동기화되지는 않습니다. 다른 PC로 옮길 때는 JSON 백업·복원을 사용하세요.

## 기본 사진

- `public/manual-images/desktop`: 사용자가 제공한 데스크탑 사진 1~33번
- `public/manual-images/mobile`: 사용자가 제공한 모바일 사진 1~8번

사진 번호를 절차 순서로 사용합니다. 기본 사진을 교체하려면 편집 모드에서 해당 화면의 `교체`를 누르거나, 소스 파일을 같은 경로에 넣은 뒤 정적 HTML을 다시 생성하세요.

왼쪽 목차는 스크롤 위치에 따라 현재 보고 있는 장을 `현재`로 자동 표시합니다. 목차를 누르면 해당 장으로 부드럽게 이동하고, 처음 나타나는 장은 가볍게 올라오는 전환 효과가 적용됩니다. 동작 줄이기 설정이 켜진 기기에서는 애니메이션을 자동으로 생략합니다.

## 실행과 검증

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
npm test
```

기본 초안만으로 정적 파일을 다시 만들려면 다음을 실행합니다.

```bash
npm run export:static
```

결과는 `release/index.html`입니다. 브라우저에서 편집한 최신 내용은 사이트의 `정적 HTML 내보내기` 버튼으로 받는 파일이 기준입니다.

완성된 기본 정적 매뉴얼만 보려면 `OPEN_FINAL_MANUAL.cmd`를 더블클릭해도 됩니다. 이 방법은 서버가 필요하지 않습니다.

## 사내 서버 배포

내보낸 HTML 파일 이름을 `index.html`로 바꿔 사내 웹 서버의 지정 폴더에 올리면 됩니다. 최종 서버에는 편집기 프로젝트 전체가 아니라 읽기 전용 `index.html`만 두는 것을 권장합니다. HTTPS와 사내 인증 또는 VPN 정책은 서버에서 별도로 적용하세요.

## 미디어 보안

- 실제 비밀번호, 인증 코드, 복구 코드, QR 코드는 촬영하지 않습니다.
- 사용자명, 내부 주소, 업무 파일명은 예시 값으로 바꾸거나 완전히 가립니다.
- SVG는 스크립트 삽입 가능성이 있어 업로드를 차단합니다.
- 긴 GIF는 용량이 커지므로 핵심 클릭만 10~20초로 촬영합니다.
